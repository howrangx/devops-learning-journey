WEEK 4: DOCKER FUNDAMENTALS

Overview
This week focuses on containerization using Docker.
You will learn to build, run, and manage containers for DevOps workflows.

Learning Objectives

By the end of this week, you will:
- Understand container concepts and architecture
- Install and configure Docker
- Use core Docker commands confidently
- Write Dockerfiles to build custom images
- Use Docker Compose for multi-container apps
- Containerize a Python application

Phase 1 Content Structure

Week 4 (Docker Fundamentals)
- Day 1: Container Concepts and Docker Basics
- Day 2: Docker Images and Containers
- Day 3: Dockerfiles
- Day 4: Docker Compose
- Day 5: Docker Networking and Volumes
- Weekend: Capstone - Containerize the DevOps Toolkit
