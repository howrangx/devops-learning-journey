WEEK 1 CAPSTONE PROJECT: DEVOPS DASHBOARD
Planning and Design Document

PROJECT OVERVIEW
Dashboard is an interactive system administration tool that consolidates
all system monitoring, analysis, and management tasks into one interface.

FEATURES REQUIRED
1. Menu System
   - Display main menu
   - Display submenu options
   - Handle user input
   - Return to menu after actions

2. System Information
   - System uptime
   - OS information
   - Kernel version
   - CPU information
   - Memory summary
   - Disk summary

3. Monitoring Functions
   - CPU load and usage
   - Memory usage details
   - Disk space analysis
   - Process monitoring
   - Network status

4. Log Analysis
   - Parse system logs
   - Count error/warning/info entries
   - Show recent entries
   - Generate log reports

5. System Health
   - Overall health status
   - Threshold checking
   - Alert generation
   - Health report

6. Process Management
   - List processes
   - Find processes by name
   - Show process details
   - Memory hogs
   - CPU hogs

7. File Operations
   - Navigate filesystem
   - List files with details
   - Search files
   - Show file permissions

8. Reporting
   - Generate system reports
   - Save reports to files
   - Display summaries
   - Log all activities

TECHNICAL REQUIREMENTS
- Use bash scripting with functions
- Error handling on all operations
- Input validation
- Clear user interface
- Logging of all actions
- Professional output formatting
- Exit codes for success/failure

DELIVERABLES
- devops_dashboard.sh (main script)
- Comprehensive documentation
- Test results
- Git commit with clean history
