# Week 1: Linux Fundamentals and Command Line

## Overview

The foundation week. Everything later in this program assumes comfort at a
Linux shell, so this week covers navigation, permissions, text processing,
process management and bash scripting, ending in a capstone that pulls all
of it into a single system administration tool.

## Learning Objectives

- Navigate the filesystem and manage files confidently from the shell
- Understand and set file permissions and ownership
- Process text with grep, awk, sed and cut
- Monitor and control system processes
- Write bash scripts with functions, error handling and exit codes
- Build a complete system administration tool

## Daily Structure

- Day 1: Linux fundamentals and command line navigation
- Day 2: File permissions and user management
- Day 3: Text processing and searching
- Day 4: Process management and system monitoring
- Day 5: Bash scripting fundamentals
- Weekend capstone: System administration dashboard

## Skills Acquired

Linux administration: filesystem navigation, permissions and ownership,
process monitoring and control, resource analysis, log parsing.

Text processing: pattern matching with grep, extraction with awk,
substitution with sed, field selection with cut, sorting and deduplication,
pipes and redirection.

Bash scripting: variables and input, conditionals and case logic, loops,
functions, error handling and exit codes, script structure.

## Technologies

Linux, Bash, coreutils, grep, awk, sed, cut, ps, top, df, free
